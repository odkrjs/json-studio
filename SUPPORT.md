# Support

Thanks for using JSON Studio.

- **Bug reports and reproducible problems:** use the bug report issue form. Include your macOS and app versions, steps, and a minimal JSON sample with private data removed.
- **Feature ideas:** use the feature request form and describe the workflow you want to improve.
- **Security issues:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Documentation:** start with [README.md](README.md), [README.zh.md](README.zh.md), and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

JSON Studio is maintained on a volunteer basis. Please allow reasonable time for a response. Before opening an issue, search existing issues to avoid duplicates.
