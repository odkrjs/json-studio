# Examples

- `compare-a.json` / `compare-b.json` — load one into each editor in **Compare** mode. Object keys are in different orders, but only real value changes are reported.
- `escaped-payload.txt` — paste into the editor and choose **Unescape String → 整段反转义** to turn the escaped payload into readable JSON.

These files are small, safe fixtures for manual testing and bug reports.
